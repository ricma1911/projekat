# Car worlds transformation

65/2023 - Dusan Maric  
Project that includes two scenes, one is inspired by Vice City looks, meanwhile the other is inspired by Los Santos. It is possible to switch worlds as you wish.

## Controls

UP button -> Increase lights intensity   
DOWN button -> Decrease lights intensity   
TAB button -> Event transformation 

## Features

### Fundamental:

[x] Model with lighting
[x] Two types of lighting with customizable colors and movement through GUI or ACTIONS
[x] TAB button click --- AFTER_1_SECONDS---Triggers---> Fade out complete and world switch ---> AFTER_1_SECONDS---Triggers---> Fade in complete and lights turned on in new world

### Group A:

[ ] Frame-buffers with post-processing   
[ ] Off-screen Anti-Aliasing  
[ ] Parallax Mapping
[x] Bloom with the use of HDR

### Group B:
[ ] Deferred Shading  
[x] Point Shadows  
[ ] SSAO
